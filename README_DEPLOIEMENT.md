# Atelier Communication Ambiante

Structure préparée pour GitHub Pages.

## Pages
- Phase 1 : Groupes 1 à 5
- Phase 2 : Groupes 1 à 5
- Phase 3 : Groupes 1 à 5

Chaque page se trouve à l'adresse relative :
`/phase-X/groupe-Y/`

Exemple : `/phase-1/groupe-1/`

Le site est prêt à être publié dans un dépôt GitHub Pages. Les QR codes imprimables seront générés à partir de l'URL publique finale du dépôt.
